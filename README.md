# giljabi-gps

## 프로젝트 개요
본 프로젝트는 **Android GPS 내비게이션 및 온라인 지도 통합** 기능을 연구하기 위한 개발 프로토타입입니다.

## 주요 목적
본 저장소와 연동된 웹사이트(GitHub Pages)는 **국토지리정보원(NGII) 공간정보 API 사용 승인 신청**을 위해 해당 애플리케이션을 식별하고 서비스 내용을 설명하기 위한 용도로 제작되었습니다.

## 상태 안내
- 본 프로젝트는 현재 **개발 중인 프로토타입**이며 실제 도로 주행용으로 적합하지 않습니다.
- 모든 기능은 개발 단계에 있으며, API 승인 여부에 따라 기능이 변경될 수 있습니다.
- 소스코드 내에 API 키 등 민감한 정보는 포함되어 있지 않습니다.
