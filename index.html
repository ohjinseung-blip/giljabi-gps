차세대 정밀 도로 지도 내비게이션 프로토타입

프로젝트 소개

본 프로젝트는 Android 기반의 GPS 내비게이션 및 온라인 지도 통합 시스템을 개발 중인 연구용 프로토타입입니다.

※ 주의: 현재 개발 단계로 실제 주행 시 사용하기에 적합하지 않습니다.

주요 기능 (개발 중)

  • Android GPS 연동 실시간 위치 추적
  • 온라인 지도 API 통합 및 경로 안내
  • 지하철 및 버스 노선 검색 지원
  • 정밀 도로 지도를 활용한 상세 내비게이션 구현
  • 별도 라이선스 지리 데이터를 활용한 오프라인 지도 권역 다운로드

데이터 및 API 정책

본 서비스는 국토지리정보원(NGII)의 공간정보 API를 활용하기 위해 준비 중이며, 승인 절차에 따라 운영될 예정입니다.

현재 소스코드 내에는 어떠한 API 키도 포함되어 있지 않으며, 데이터 사용은 관련 규정을 엄격히 준수합니다.
